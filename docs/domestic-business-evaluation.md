## 标签与计算口径

搜索为**需求条件银标**：硬过滤不满足为 0，满足全部需求维度为 2、部分为 1、均不满足为 0。每题穷举标记全库；MRR/Recall 以 grade=2 为相关，nDCG 增益为 `2^grade-1`。硬过滤由用例显式提供，**未评测自然语言自动抽取过滤条件**。规则可能偏好显式术语、有利于词法检索，不等于 HR 对个人匹配度的判定。

证据由助手阅读原文后编写引文锚点：切块包含全部支持引文为 2、部分为 1、无引文为 0；MRR/Recall 以 grade≥1 为相关。完整支持@k 要求前 k 个片段的引文并集覆盖所有支持点。仅正文可成为正例，派生关键词和概述不是答案证据。构建器校验引文存在于原文且未被切块丢失。格式变化使用保留事实的原文子串，如“本科及以上”。引用覆盖不是生成答案准确率。

无答案指完整提供的 JD 未直接给出所问事实，不能推断现实中不存在该要求。无相关项的 MRR/Recall 不适用，不作为 0 或 1 混入均值；另行测拒答。指标按查询宏平均。配对 bootstrap 固定种子、3,000 次，证据按岗位组、搜索按查询意图抽样；区间不消除标签偏差与样本小的局限。

首轮 v4 审计发现“token2wav / 语音/音频生成”和“生成式视频”被规则漏标，v4.1 增补原文支持的同义表达并重建三个独立索引，没有改排序超参数。**标签修正看过测试输出，最终称回归测试。** 首轮 M3 dense nDCG@10=0.5883，修正后=0.6133，原结果保留于 `run2/`。不存在已完成的人类标注。

## 全库搜索结果

以下测试均值来自 18 个有相关岗位查询。dense 取最多 200 切块，按首个命中去重成岗位；hybrid 将 dense 岗位排名与全部候选 BM25 排名用固定 RRF k=60 融合。BM25 使用现有中文单字/英文词分词，不代表最佳词法实现。只使用 BGE dense，无 sparse/multi-vector、无 cross-encoder 重排。

| 方案 | MRR@10 | Recall@20 | nDCG@10 |
|---|---:|---:|---:|
| 条件内随机排列理论值 | 0.1922 | 0.2958 | 0.2490 |
| 原有关键词过滤/规则排序 | 0.0903 | 0.1667 | 0.1443 |
| BM25 | 0.7539 | 0.7439 | 0.7035 |
| small 512 dense | 0.7824 | 0.7052 | 0.6694 |
| small 512 + BM25 | 0.8065 | **0.7831** | **0.7867** |
| M3 512 dense | 0.6765 | 0.6562 | 0.6133 |
| M3 1024 dense | 0.6765 | 0.6562 | 0.6133 |
| M3 512/1024 + BM25 | **0.8385** | 0.7658 | 0.7658 |

M3 融合对比同模型纯向量：MRR **+0.1619**（相对 +23.94%），Recall **+0.1096**（+10.96 个百分点），nDCG **+0.1526**（相对 +24.88%，差值 95% CI [0.1073, 0.2014]）。这是**检索策略改进**，不能写成更换 embedding 的提升。

M3 融合对比 BM25：nDCG 相对 +8.86%，差值 CI [-0.0137, 0.1398]，未确认稳定优势。small 融合 nDCG/Recall 点估计更好，M3 融合首个完全相关岗位的排名更好。M3 纯向量对比 small，nDCG 下降 8.39%，差值 CI [-0.1251, 0.0154]，不能宣称 M3 全面最优。

所有实测策略 Top20 硬过滤违规数为 0。无相关岗位题：西宁量子纠错因城市过滤返回空集；蛋白质晶体衍射仍返回无关候选。**尚无可靠的全库“没有合适岗位”判定**，UI 将结果作为待核查候选，不作为确定匹配结论。

## 资料缺失与拒答

归一化向量在 Chroma 默认平方 L2 下用 `cosine=1-distance/2`，只看 source_text 最高相似度。开发集选择无答案误放行≤10%时保留最多有答案题的阈值，测试集不调阈值。

| 测试策略 | 无答案误放行率 | 有答案误拒绝率 | 候选覆盖率 |
|---|---:|---:|---:|
| 总是返回 | 100% | 0% | 100% |
| 总是拒绝 | 0% | 100% | 0% |
| small 校准阈值 | 18.75%（3/16） | 50%（12/24） | 37.5%（15/40） |
| M3 校准阈值 | 18.75%（3/16） | 50%（12/24） | 37.5%（15/40） |

放行候选中 20% 没有直接答案。相似话题不等于支持所问事实，余弦阈值会同时错放、错拒。**这些策略未自动启用**：policy 导出为 `production_approved=false`。生产 `/evidence/check` 无验证策略时返回 `not_calibrated` 并拒绝给出可回答结论；错误文件、模型/切块身份不符、未审核策略也关闭。该新增端点不意味着现有材料生成已有可靠自动拒答能力。

## 原因分析与选型

1. 原规则只对部分问法抽词，长自然语言经 SQL 字面过滤会漏岗位，固定规则分也不能充分表示意图。新入口先取得所有满足硬条件的岗位再排序；保留旧规则兼容。不能只用旧规则的差表现夸大相对提升，必须比较 BM25。
2. 向量相似容易混淆宽泛主题与具体约束。例如实时系统查询中 M3 将 Linux 内核岗排在明确 RTOS 岗之前；small 和融合将 RTOS 岗排第一。RRF 利用两路排名互补。这是逐题输出支持的解释，不是已证明的模型内部因果机制。
3. 条件词银标可能低估语义模型；语音例子已证实漏标风险。v4.1 修复同义词仍不能替代完整人工语义判定。人工需核对完整 JD、否定、优先/必需，不能照抄命中规则。
4. 972 片段中 small 512 截断 49 个，M3 512 截断 1 个，M3 1024 为 0；M3 两长度指标相同，**不能把提升归因于长上下文**。RTX 5060 Laptop GPU 本轮暖证据 P95：small 约 10.17 ms，M3 1024 约 25.00 ms；仅局部诊断计时，非独立并发压测或端到端 SLA。
5. UI 默认无需向量模型的 BM25，允许选择既有 M3 语义/融合；未根据小样本自动迁移生产 embedding。small 保留为低资源备选。不能写“实验证明 M3 全面优于 small”。

## 人工复核闭环

冻结目录有空白 `human_review_evidence.jsonl`、`human_review_search.jsonl`。两位标注者独立给 0/1/2 标签；问题、完整 JD、切块分别从同目录 search_queries/jobs/evidence JSONL 按 ID 关联。分歧需第三人填写 `adjudicator`、`adjudicated_grade`。

```powershell
.venv\Scripts\python.exe -X utf8 -m tools.evaluate_business_reviews --dataset outputs/domestic_business_v4_20260921/frozen_v41 --run outputs/domestic_business_v4_20260921/run_v41 --evidence-reviews path/to/completed_evidence.jsonl --search-reviews path/to/completed_search.jsonl --reviewer-a reviewer_a --reviewer-b reviewer_b --output outputs/human_review_result
```

导入器拒绝缺失、重复、越界和未仲裁标签，报告一致率/Cohen's kappa，重算保存排名及仅开发集拟合的阈值，输出新报告。它验证完整性，不能证明标注者真的独立工作；原助手引文覆盖率不会自动变成人工指标。**当前尚无人类完成复核，没有人工金标成绩。**

项目已具个人使用的核心闭环，正式数据/索引和新接口已验证。无答案识别、生成事实性、用户需求代表性、公网多用户隔离与运行稳定性未由检索分数证明。MRR/Recall 不是匹配准确率、面试通过率或完整商用上线证明。
