# 国内 AI 求职助手

## 范围

系统只处理中国境内职位，默认面向 2027 届校招/实习，重点排序 AI 应用开发、Agent/智能体开发、AI 软件开发和大模型应用开发。国外历史语料仍可留在旧目录作为兼容数据，但国内搜索接口、生产索引和新评测集均不使用它们。

## 简历策略

- 输入仅接受 PDF。
- 原 PDF 只读；系统复制原始字节到候选人目录，提取文字并生成检索画像。
- 不修改、润色或回写 PDF 中的任何内容。
- 姓名、电话、邮箱等信息不通过国内岗位搜索接口返回。
- 2027 届是基于用户秋招上下文设置的检索默认值，画像中明确标记为推断，不伪装成简历原文。

## 数据源策略

自动同步仅接入无需登录、无需验证码、允许公开访问的页面，分为两层：

- **逐岗位官方源**：百度 2027 AIDU、大疆 2027 拓疆者、麒麟软件、OPPO、美团，以及荣耀重点校招职位。
- **公告级补充源**：企业官网或高校就业网公开的 2027 届校招公告。公告记录明确标记为“岗位合集”，不会伪装成逐岗位 API 数据；投递前仍须打开企业投递页复核。

当前公告级补充源覆盖 28 家企业：传音控股、驭势科技、挚文集团、度小满、中景芯创、中科曙光、普渡科技、星环科技、歌尔集团、星宸科技、容知日新、小米集团、中国电子云、得物、睿联技术、启云方、千寻智能、海光信息、东风研发总院、中联重科、字节跳动、拼多多、小鹏汽车、华诺星空、扬腾创新、去哪儿旅行、宁德时代和华勤技术。与 6 家逐岗位官方源合计，当前去重覆盖 34 家公司。

系统不会绕过登录或反爬机制，也不会调用 BOSS 直聘、智联招聘、猎聘、前程无忧等平台的内部接口。此类平台没有面向普通开发者、覆盖全量职位的通用公开 API；如后续获得企业授权或正式开放平台凭据，应新增官方 API 适配器，不能把网页内部接口当公共 API。

同步任务具备以下保护：

- 先检查 `robots.txt` 的明确禁止规则；明确禁止时停止。
- 单个数据源解析为 0 个岗位时，本轮失败且不改变已有岗位状态。
- 公告级补充源只要有任一配置页面无法访问或未通过“2027 + 企业名称”校验，本轮整体失败并保留旧数据，避免部分抓取造成误关岗。
- 岗位连续 3 次成功同步均未出现，才标记为关闭。
- 每次内容变化保留快照，抓取运行记录保留成功/失败与数量。

## 运行

```powershell
.\.venv\Scripts\uvicorn app.main:app --reload
.\.venv\Scripts\streamlit run streamlit_app.py
```

自动同步默认关闭。确认本机长期运行后，可在 `.env` 设置：

```dotenv
DOMESTIC_SYNC_ENABLED=true
DOMESTIC_SYNC_INTERVAL_MINUTES=360
DOMESTIC_SYNC_BUILD_INDEX=true
```

手动流程：

1. `POST /api/domestic/sources/refresh` 一次完成全部来源同步和国内生产索引重建。
2. `GET /api/domestic/jobs/search` 筛选和排序岗位。
3. `POST /api/domestic/jobs/{job_id}/fit` 使用 PDF 原文和智谱模型分析匹配度。
4. `PUT /api/domestic/jobs/{job_id}/application` 保存投递阶段。

前端“**一键更新岗位**”调用上述刷新接口。`/sources/sync` 和 `/index/rebuild` 仍作为维护接口保留，但正常使用时不需要分别点击。

## 智谱配置

现有 OpenAI-compatible 智谱配置可以继续使用，不需要更换供应商。系统沿用 `.env` 中的 API Key、base URL 和模型名。API Key 只保存在本机环境变量，不写入数据集或接口响应。若 Key 失效、额度不足或模型下线，规则检索和投递看板仍可用，只有生成式匹配报告会失败并返回明确错误。

用于岗位匹配的模型调用默认关闭深度思考，并限制为 1200 个输出 token、90 秒超时和最多 1 次重试，以适配交互式页面。证据对齐与匹配分由本地确定性逻辑先完成，模型只负责定性建议。

## 评测数据

运行：

```powershell
.\.venv\Scripts\python tools\build_domestic_eval_dataset.py
```

会生成 `data/eval_dataset/domestic_job_search_v1`：官网岗位、检索查询与相关性银标、候选人-岗位匹配银标和评测报告。银标可做持续回归测试，但不能替代人工金标；投递前必须打开企业官网复核岗位是否仍然有效。
